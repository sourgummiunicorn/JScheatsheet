VARIABLES AND STATE

What is true right now?

A variable gives a name
to a value.

USE let

When the value can change.

let isLightOn = false;
isLightOn = true;

The name stays the same. The value can become something new.

USE const

When you will not reassign it.

const buttonLabel =
  "Turn lamp on";

Use a clear name so a future reader can understand the value.

02

CONTROL STRUCTURES

Choose behavior with a question.

if asks.
else handles the other case.

script.js
if (isLightOn) {
  lampStatus.textContent = "ON";
  lamp.classList.add("glowing");
} else {
  lampStatus.textContent = "OFF";
  lamp.classList.remove("glowing");
}
TRUE

If the light is on
show ON and add the glow.

FALSE

Otherwise
show OFF and remove the glow.

Read it aloud: “If this is true, do this. Otherwise, do that.”
