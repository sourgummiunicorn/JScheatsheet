VARIABLES AND STATE

What is true right now?

A variable gives a name to a value.

USE let

When the value can change.

let isLightOn = false;
isLightOn = true;

The name stays the same. The value can become something new.

USE const

When you will not reassign it.

const daysInAWeek = 7;

A week always has 7 days, so this is a value we do not need to change.

A STATE MAP

OFF
falseclick→ON
true

isLightOn describes the lamp at one moment. It is a boolean, which means it can only be true or false.

FUNCTIONS: INPUTS AND OUTPUTS

Give a function something. Get a result.

Inputs go in.
Outputs come back.

PARAMETERS VS ARGUMENTS

Recipe blanks and real ingredients.

function makePizza(crust) {
  return "Pizza with " + crust;
}

makePizza("thin");

crust is a parameter: a blank in the recipe. "thin" is an argument: the real value you give it.

TRY A FUNCTION

Temperature converter

function celsiusToFahrenheit(c) {
  return (c * 9 / 5) + 32;
}
15°C → 59°F

The number in c is the input. return sends the answer back out.

CONTROL STRUCTURES

Choose behavior with a question.

if asks.
else handles the other case.

script.js
if (energyLevel < 60) {
  activity = "rest";
} else if (energyLevel < 80) {
  activity = "snack";
} else {
  activity = "create";
}
IF

Below 60
Choose rest.

ELSE IF

60–79
Choose a snack.

ELSE

80 or more
Choose create.

Read it aloud: “If this is true, do this. Otherwise, check the next question.”

TRY IT

Set an energy level.

80 → activity = "create"
06

LOOPS

Repeat a step on purpose.

A loop repeats.
A condition stops it.

for LOOP

Use it when you know the list.

let students = ["Yixin", "Sarah", "Erin", "June", "Xiran"];

for (let i = 0; i < students.length; i++) {
  console.log(students[i]);
}
Ready to find students.

while LOOP

Use it while a condition is true.

let count = 3;

while (count > 0) {
  console.log(count);
  count = count - 1;
}
Ready to count down.

Important: change something inside a while loop, or it may never stop.
