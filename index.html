01

JAVASCRIPT CONCEPTS

Your starter toolkit.

Read each tiny program
like a recipe.

JavaScript does not need to feel mysterious. It works with different kinds of information, remembers things, makes choices, and talks back to the person using the page.

🍦

DATA TYPES

Different scoops of information.

let scoops = 3;          // number
let flavor = "cookie dough"; // text
let isYummy = true;      // yes / no

A number counts scoops. Text stores words. A boolean answers a yes-or-no question.

🍬

VARIABLES

A labeled candy jar.

let candies = 100;
candies = candies + 10;

candies is the label on the jar. The amount inside can change from 100 to 110.

🍭

OPERATORS

Math and questions.

let total = 5 + 3;
let hasEnough = total > 6;

+ adds. > asks “is this bigger?” Operators help code calculate and compare.

📖

CONTROL FLOW

A choose-your-own-adventure.

if (score > 50) {
  console.log("Pass!");
} else {
  console.log("Keep trying!");
}

Code follows one path when the answer is true and another path when it is false.

🪄

FUNCTIONS

A spell you can reuse.

function cheer(name) {
  console.log("Go, " + name + "!");
}

cheer("Iva");

A function packages steps under one name. Call it whenever you want those steps again.

🥚

ARRAYS & OBJECTS

A carton and a character card.

let fruits = ["apple", "banana"];
let student = {
  name: "H", age: 12
};

An array keeps a list in order. An object groups details that belong to the same thing.

🍕

INPUT & OUTPUT

Take an order. Show a result.

let topping = prompt("Pick a topping");
alert("Pizza with " + topping + "!");

prompt listens to a person. alert sends a message back to the screen.

02

VARIABLES AND STATE

What is true right now?

A variable gives a name
to a value.

USE let

When the value can change.

let isLightOn = false;
isLightOn = true;

The name stays the same. The value can become something new.

USE const

When you will not reassign it.

const buttonLabel =
  "Turn lamp on";

Use a clear name so a future reader can understand the value.

03

CONTROL STRUCTURES

Choose behavior with a question.

if asks.
else handles the other case.

script.js
if (isLightOn) {
  lampStatus.textContent = "ON";
  lamp.classList.add("glowing");
} else {
  lampStatus.textContent = "OFF";
  lamp.classList.remove("glowing");
}
TRUE

If the light is on
show ON and add the glow.

FALSE

Otherwise
show OFF and remove the glow.

Read it aloud: “If this is true, do this. Otherwise, do that.”
